# 검증과 인수 기준
버전 3.0. TC는 사용자 가치/오판 방지 검증이며 단순 구현 복제 테스트를 의미하지 않는다.
fixture는 synthetic임을 명확히 하고, 실제 평가 정확도 근거로 사용하지 않는다.

## E2E 인수
관리자/분석가 로그인 → 새 사건 → 세 플랫폼 fixture 또는 수동 파일 입력
→ 품질 탭 → timeline → edge 원문 확인 → claim 변형 검토
→ 반복 행동 근거 → 가설과 반대 증거 → 보고서 생성/검토/승인
→ export/manifest 검증 → 새 관측 추가 → 옛 보고서 불변.
작은 화면 및 한국어/중국어 글꼴·줄바꿈·표/그래프 모두 확인.
실제 API E2E는 별도 표시하고 mock 네트워크 성공으로 대체하지 않는다.

## 출시 판단
필수 테스트가 실패하면 관련 범위를 완료로 표시하지 않는다.
분석 baseline이 아직 descriptive_only면 통계적 검증 완료라고 하지 않는다.
OCR 실제 모델을 시험하지 않았다면 이미지/OCR 기반 실제 탐지 완료라고 하지 않는다.
원문 내용 진위·사건 정답이 없으면 일반 정확도·배후 탐지 정확도를 보고하지 않는다.
세 플랫폼 비교 가능과 세 플랫폼 자동 수집 가능은 다른 인수 항목이다.

## 성능
명시한 CPU/RAM/이벤트 수/계정 수/후보 cap/B/모형 버전에서 측정.
목표 미달 시 병목을 기록하고 근거 없는 최적화 확약 금지.
그래프 node 제한/분석 cap/누락이 결과 해석에 미치는 영향 함께 제공.
